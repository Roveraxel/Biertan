# Audit of uncommitted AI edits found on the Mac, 2026-11-16 (by Claude)

Files touched (outside the task board): `scripts/world/world_builder.gd`, `scripts/world/trees.gd`, `scripts/world/mats.gd`.
Saved unchanged as `.ai/proposals/nemotron_ground_trees_haystacks.patch`. Not applied.

## Result: REJECTED as written (the game would not compile)
I exported the project with these three files in place:
- `mats.gd`, `blend()`: `var ca := a.albedo_color` and `var cb := b.albedo_color` fail with "Cannot infer the type", because `a` and `b` are typed `Material`, which has no `albedo_color`. This stops every script that depends on `Mats` from compiling, so the game does not load. Fix: cast to `StandardMaterial3D` first.
- `world_builder.gd`, `_occupied_ground()`: calls `dist_to_segment(...)`, which exists only as `Level.dist_to_segment` (static). It needs `Level.dist_to_segment`. This would be the next error.
- `_grass_patches()`: one `Batch` plus `commit` per patch, hundreds per level, makes hundreds of mesh nodes and will hurt the web build; the discs sit at y 0.015, near the road layers (0.012 to 0.014), so they can flicker (z-fighting). It uses `randf()` (global RNG), which breaks the deterministic `NetRandom` rule.
- `_haystacks()`: uses `candidates.shuffle()` (global RNG, non-deterministic), adds decor after the level is built, and adds more haystacks, while the haystack complaint was about how they look.
- `_wilds()`: replaces `hash(L.id)` with `_str_hash(...)`. That changes every forest layout for no benefit.
- `leaf_color(..., spring)` and `spruce_young()` are harmless in themselves.

## What was done instead
Claude implemented the same goals (ground, trees) in a version that compiles and was checked in screenshots: new `textures/px_meadow_diff_1k.png` for village ground (`Mats.ground()`), the macro veil on villages, one-colour-family tree crowns (`Trees.leaf_color`), warmer cobbles.

## Rule added
An AI that cannot run `godot --headless --export-release Web` must not edit `.gd` files. It writes a patch or a proposal to `.ai/proposals/` and Claude applies and checks it. All other edits are checked by Claude: Claude diffs the working folder against the last commit at the start of every session and exports the project before publishing.
